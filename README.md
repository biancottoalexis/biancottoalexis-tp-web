
# Le château mystérieux

## Présentation

Le château mystérieux est un jeu
d'aventure à choix multiples.

Le joueur doit explorer un château
pour trouver un trésor.

## Technologies utilisées

- HTML
- CSS

## Fonctionnement

Le jeu contient 14 pages HTML :
- 1 page d'accueil
- 13 scènes

Le joueur clique sur des boutons
pour choisir son chemin.

Il existe 3 fins différentes :
- Trouver le trésor
- Rester enfermé
- Quitter le château

Chaque page possède une image de fond.

## Lancer le jeu

Ouvrir le fichier index.html
dans un navigateur.
