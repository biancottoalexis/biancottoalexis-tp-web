
# Le château mystérieux

## Présentation du projet

Le château mystérieux est un jeu d'aventure textuel
à choix multiples réalisé en HTML et CSS.

Le joueur incarne un aventurier qui explore un vieux
château à la recherche d'un trésor caché.

À chaque étape, le joueur doit faire des choix
qui vont modifier la suite de son aventure.

## Technologies utilisées

- HTML : pour créer les pages du jeu.
- CSS : pour les couleurs, les images et les boutons.

## Organisation du projet

Le projet contient 14 pages HTML :
- 1 page d'accueil (index.html)
- 13 pages pour les différentes scènes

Les fichiers sont organisés dans plusieurs dossiers :

- index.html : page d'accueil du jeu
- style.css : mise en forme du jeu
- pages/ : les 13 scènes du jeu
- images/ : les images de fond des scènes
- arbre-navigation.pdf : schéma des choix possibles
- README.md : présentation du projet

## Fonctionnement du jeu

Le joueur commence sur la page d'accueil.

Il clique sur "Commencer le jeu" pour entrer
dans le château.

Ensuite, il doit choisir entre plusieurs chemins
pour avancer dans l'histoire.

Le jeu possède trois fins différentes :

- Bonne fin : le joueur trouve le trésor.
- Mauvaise fin : le joueur reste enfermé.
- Fin alternative : le joueur quitte le château
  sans trouver le trésor.

Le joueur peut recommencer après chaque fin.

## Comment lancer le jeu

1. Télécharger le dossier du projet.
2. Ouvrir le dossier dans Visual Studio Code.
3. Ouvrir le fichier index.html dans un navigateur.
4. Cliquer sur "Commencer le jeu".

## Arbre de navigation

Le fichier arbre-navigation.pdf présente
